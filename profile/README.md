# CronAI

Markdown-native and AI-assisted tooling, built in the open where it makes sense to be.

## Projects

| Project | What it is |
|---|---|
| [VaultOre](https://github.com/cronai-labs/vaultore) | A Markdown-native AI workflow engine for Obsidian — run AI, TypeScript and shell cells inside your notes, sandboxed in containers, on a cron schedule. |

## How we work

Every change reaches `main` through a pull request: one issue, one branch, one squash commit.
Conventional Commits, automated semver, and a single required CI check per repository. The
conventions live in [`.github`](https://github.com/cronai-labs/.github).
